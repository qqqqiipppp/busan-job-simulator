## 북항 흑상어 자료와 명칭

- [국립수산과학원, 2026-10-06 공식 보도자료](https://nifs.go.kr/news/actionNewsView.do?MENU_ID=M0000307&NEWS_D_DATE_BEGIN=2000-01-01&NEWS_D_DATE_END=2100-01-01&NEWS_D_SUBJECT=&NEWS_SEQ=4915&PARENT_NEWS_HG_CODE=&selectPage=): 북항의 실제 상어 '부캉이'가 흑상어임을 확인했습니다. 넓고 둥근 주둥이 등의 생물 특징을 참고했으며 첨부 사진을 자산으로 복제하지 않았습니다. 이 보도자료에는 공공누리 제1유형 표시가 있으나, 별도 공식 캐릭터의 이미지 이용허락을 뜻하지 않습니다.
- [부산 동구, 북항 상어 캐릭터 공모전 안내, 2026-09-28](https://www.bsdonggu.go.kr/board/view.donggu?boardId=BBS_0000025&dataSid=5097870&menuCd=DOM_000000103001006000&paging=ok&startPage=1): 공식 페이지의 공모 안내와 첨부 존재를 확인했습니다. 상세 페이지 재조회는 타임아웃이 있어 확정된 캐릭터 원본·사용허락까지 확인한 것으로 보지 않았습니다.

이번 확인 범위에서 확정된 공식 '부캉이' 캐릭터의 자유 이용 조건은 확보하지 못했습니다. 사용자 요청의 대안에 따라 자연의 북항 흑상어를 모티브로 한 창작 디자인을 제작하고 **북항상어 인턴**으로 표시합니다. 공식 캐릭터·기관의 승인이나 제휴를 뜻하지 않습니다.

## 프로젝트 사용 방식

웹은 dist/assets/characters/의 상대경로 PNG를 읽습니다. scripts/build-offline.mjs가 동일한 세 이미지를 data URL로 넣어 단일 HTML에서 외부 이미지 요청 없이 표시합니다. 테마·캐릭터 움직임은 dist/sky-theme.css에서 관리하며 동작 줄이기 설정에서는 애니메이션·호버 이동을 끕니다. 새 자산을 만들 때는 별도 파일로 보존하고 프롬프트와 제작 경로를 함께 기록하세요.
